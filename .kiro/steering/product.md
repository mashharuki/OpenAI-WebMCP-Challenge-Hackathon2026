# Product Overview

OpenAI WebMCP Challenge is a reference-style application suite that makes browser UI actions available to both people and browser-based AI agents, while demonstrating x402 payment-gated server resources.

## Core Capabilities

- A React todo experience exposes shared actions through declarative and imperative WebMCP tools.
- A Hono resource server protects paid resources with x402 payment middleware and AgentKit integration.
- An EVM facilitator verifies and settles x402 payments for the resource server.

## Target Use Cases

- Demonstrating how a normal Web UI can offer safe, discoverable agent actions without separating human and agent workflows.
- Prototyping paid API/resource access using x402 and a local or configured facilitator.
- Testing experimental WebMCP support in Chrome against a small, inspectable application.

## Value Proposition

The project keeps user-facing behavior and agent-facing behavior on the same application state and validation paths. This makes WebMCP features demonstrable without creating a parallel, drifting API surface, while the x402 services provide a practical example of payment-aware agent infrastructure.
