# Product Overview

AdGate for WebMCP is a publisher monetization demo for the agent-native web. A premium browser tool pauses for an explicit human choice: view a short sponsor message for free access or approve a small x402 testnet payment to continue immediately.

## Core Capabilities

- A polished recipe publisher exposes a premium analysis through one imperative WebMCP tool.
- The publisher is the fictional `Open Table Journal`; the fixed demo recipe is `Roasted Chickpea Quinoa Bowl`, and the fictional self-sponsor is `Open Table Weekly` using only repository-owned visual assets.
- A shared gate coordinator keeps the agent invocation pending while the human chooses the unlock path in the visible page.
- A Hono resource server accepts either a short-lived sponsor grant or an x402 payment for the same premium resource.
- An EVM facilitator verifies and settles Base Sepolia payments for the paid path.

## Target Use Cases

- Publishers and creators exploring sustainable access models as agents replace conventional browsing and ad impressions.
- People who want to keep free sponsor-supported access or pay a small amount when speed matters.
- Browser agents that need structured, reliable access while preserving human control for consequential choices.

## Value Proposition

AdGate makes human-agent collaboration part of the protocol flow rather than a chat-side explanation. The page, person, and agent share one pending action; either sponsor attention or x402 payment can unlock the same resource, giving publishers a credible free-and-paid model without hiding consent or duplicating business logic.

The sponsor prototype verifies a server-issued session and minimum elapsed time, while browser UX requires eight visible seconds. It does not claim fraud-proof attention measurement. The paid path is best-effort live and otherwise demonstrated with a same-release local recording; the sponsor path remains the required public live path.
